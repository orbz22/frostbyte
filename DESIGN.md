# FrostByte Design System

The comprehensive UI/UX Design System Specification has been documented in [`docs/DESIGN.md`](docs/DESIGN.md).

It contains:
- **Design Philosophy:** "Cyber Frost" & Windows 11 Fluent 2.0 (Mica/Acrylic)
- **Dimensions & Form Factor:** Fixed 560px × 740px widget layout
- **Color Palette & Design Tokens:** Base ground, acrylic surfaces, cyan/emerald/amber/crimson accents
- **Typography Hierarchy:** Segoe UI Variable + Cascadia Code / Monospace
- **Component Breakdowns:** Header, Dual Thermal Gauges, Smart Governor (Instant Cool Auto/Manual + Auto-Tame), Rogue Alert Banner, Process Table, and Settings Modal
- **State Matrix & AI Generator Prompts:** Ready-to-use specifications for Google Stitch, Figma AI, and v0
